# PLAN

This color previewer renders different colors of the stl file in a 3d viewer.
optionally selected colors can be applied to the stl files. 
aka they will be layered on top of each other and rerendered with the selected colors. 

## technologies
- three.js
import STLLoader from 'https://threejs.org/examples/jsm/loaders/STLLoader.js';
